# 🚀 Advanced Animated Portfolio 

An elite, high-performance portfolio structure designed for modern web standards without the need for Node.js or complex build environments.

## 🛠 Tech Stack (No-Node Environment)
* **HTML5 / CSS3:** Using CSS Grid, Flexbox, and Custom Properties (Variables).
* **GSAP (GreenSock):** For industry-level animations and scroll-driven interactions.
* **Lenis:** To achieve premium, buttery-smooth momentum scrolling.
* **Lucide/FontAwesome:** Scalable vector icons for clean UI.

---

## ✨ Advanced UI Features
* **Parallax Scrolling:** Dynamic background elements that move at different speeds.
* **Entrance Sequences:** Staggered animations for text and cards when the page loads.
* **Custom Cursor:** A hardware-accelerated magnetic cursor that reacts to interactive elements.
* **Glassmorphism:** Frosted glass UI components using `backdrop-filter`.
* **Reveal on Scroll:** Elements that slide or fade into view based on the user's scroll position.
